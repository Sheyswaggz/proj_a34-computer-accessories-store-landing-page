# Computer Accessories Store Landing Page

A clean, professional static landing page for a computer accessories store that showcases products and provides essential business information. The page serves as a digital storefront to attract customers and display the store's offerings using only HTML, CSS, and basic JavaScript for enhanced user experience.

## Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Semantic HTML5**: Clean, accessible markup following web standards
- **Product Showcase**: Grid-based product display with 8 product placeholders
- **Business Information**: Dedicated section for store address, hours, and contact details
- **Modern Navigation**: Intuitive header with navigation menu
- **Hero Section**: Eye-catching hero area to capture visitor attention
- **Social Integration**: Footer with social media links
- **Performance Optimized**: Lightweight codebase for fast loading times

## Technology Stack

- **HTML5**: Semantic markup for structure and accessibility
- **CSS3**: Modern styling with responsive layouts and animations
- **Vanilla JavaScript**: Pure JavaScript for interactions and dynamic functionality
- **No Dependencies**: Framework-free implementation for maximum performance

## Local Development

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A local web server (optional, but recommended)

### Running Locally

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd proj_a34-computer-accessories-store-landing-page
   ```

2. Open the project:
   - **Simple method**: Open `index.html` directly in your web browser
   - **Recommended method**: Use a local development server

3. Using a local server:

   **With Python:**
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

   **With Node.js (http-server):**
   ```bash
   npx http-server
   ```

   **With VS Code Live Server:**
   Install the Live Server extension and click "Go Live" in the status bar

## Deployment

### GitHub Pages

This project is ready for deployment on GitHub Pages:

1. Push your code to GitHub
2. Go to repository Settings → Pages
3. Select the branch (usually `main`) and root folder
4. Click Save
5. Your site will be published at `https://<username>.github.io/<repository-name>`

### Other Hosting Options

The project can be deployed to any static hosting service:
- **Netlify**: Drag and drop the project folder
- **Vercel**: Connect your GitHub repository
- **Cloudflare Pages**: Connect via Git integration
- **Amazon S3**: Upload files and enable static website hosting
